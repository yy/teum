# Security policy

## Supported versions

Until teum reaches 1.0, only the latest published release receives security and
data-integrity fixes.

## Reporting a vulnerability

Please open a draft security advisory from the repository's Security tab, or
use GitHub's private vulnerability-reporting form when it is available, rather
than opening a public issue. Include the affected command, operating system,
teum version, reproduction steps, and potential impact. Do not include real
time-tracking data or credentials in the report.
